# 08_MANUFACTURING_DEFECTS Dataset

## Overview
Manufacturing operational dataset (3,240 records) linking machine operating parameters with production costs, scrap rates, and defect occurrences.

## Target
- DefectStatus: 1 (Defect present: 84.04%), 0 (No defect: 15.96%)

## Operational Use
- Scrap cost and rework financial loss modeling in INR.
