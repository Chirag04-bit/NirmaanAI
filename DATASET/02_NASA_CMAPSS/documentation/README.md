# 02_NASA_CMAPSS Turbofan Engine Degradation Dataset

## Overview
Turbofan engine run-to-failure degradation simulation generated by NASA Ames Prognostics Center of Excellence (PCoE).

## Subsets
- FD001: 1 operating condition, 1 fault mode (HPC degradation) - 20,631 train / 13,096 test
- FD002: 6 operating conditions, 1 fault mode - 53,759 train / 33,991 test
- FD003: 1 operating condition, 2 fault modes - 24,720 train / 16,596 test
- FD004: 6 operating conditions, 2 fault modes - 61,249 train / 41,214 test

## Target
- Remaining Useful Life (RUL) in operating cycles.

## Critical Leakage Guardrail
Split trajectories strictly by engine unit_number to prevent temporal leakage between train and test sets.
